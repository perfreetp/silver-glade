# 烬迹 BurnTrace · 火烧迹地边界重建工具

面向灾后林地评估的浏览器端工具：导入迹地影像与高程，自动提取火场边界，
用布尔运算消除自交与碎片，支持拖动顶点实时修边、贴地/抬升两种三维显示、
按受损程度分级填充，并导出 GeoJSON。

技术栈：原生 TypeScript + Web Components（无框架）+ three.js + manifold-3d（WASM）。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览构建产物 http://127.0.0.1:4173
```

首次打开可直接点击「载入演示数据」，会加载 `public/samples/` 下的合成迹地影像
（960×720，1200 m × 900 m，含 WGS84 地理参照）与配套 DEM（ESRI ASCII，480×360）。

## 四个模块

| 模块 | 作用 |
| --- | --- |
| 01 影像导入 | 拖入正射影像（PNG/JPG/WEBP）与高程（`.asc`/`.txt` 或灰度图）；设置地理参照与未过火参考色 |
| 02 边界提取 | 过火指数热力图、阈值/碎片/平滑参数、「自动调参」、处理管线与提取结果对比 |
| 03 修边编辑 | 移动 / 插入 / 删除顶点、环列表管理、简化与清理、布尔规整、显示模式与垂直夸张 |
| 04 面积统计 | 分级面积与占比、环形图、沿边界剖面、点位查询、分级阈值、GeoJSON 导出 |

## 关键技术实现

### 火场提取（颜色差异）

`src/core/detect.ts`

1. **过火指数**：以「未过火参考色」为基准，组合四类颜色差异——
   亮度下降（火烧后反射率降低）、绿度损失、色相偏移、灰烬的低饱和暗色；
   归一化后经 `smoothstep` 压缩到 0..1，再做一次 3×3 箱式平滑抑制噪声。
2. **等值线**：在指数场外围补一圈 0 后做 marching squares，贴边迹地会沿影像
   边缘自然闭合；鞍点（5/10 号模式）按单元中心均值消歧。
3. **布尔规整**：等值线交给 manifold-3d 的 `CrossSection`（Clipper2 内核）做
   `EvenOdd` 并集与 `decompose`，重叠环合并、自交自动消解，得到「外环 + 孔洞」。
4. **碎片过滤**：按面积阈值剔除孤立小斑块与过小的孔洞。

### 边界模型与三角化

`src/core/kernel.ts`、`src/core/model.ts`

- 边界以「环 + 角色（外环/孔洞）」保存，编辑后统一经 `NonZero` 并集规整。
- 三角化用 manifold 的 `triangulate`（保形、支持孔洞），外环强制逆时针、
  孔洞强制顺时针。凹多边形、孔洞、自交输入均有单元测试覆盖。
- 对外暴露 `union / difference / decompose / simplify / triangulate`，WASM 实例单例加载。

### 贴地渲染

`src/view/boundaryView.ts`、`src/view/refine.ts`

- 边界顶点按 **坡度自适应** 加密：`step = clamp(base/(1+gain·tan θ))`，陡坡更密。
- 加密后三角化，再按「最长边二分」递归细分（共享边共用中点缓存，不留缝），
  使贴地面足够细以贴合地形起伏。
- 每个顶点取 DEM 双线性高程（乘垂直夸张）后作为 Y 值，因此填充面随地势起伏；
  抬升显示则把同一三角网整体平移到「地形最高点 + 抬升高度」。
- 贴地偏移随地形网格分辨率自适应，避免陷进粗三角面的地形。

### 受损分级

`src/core/severity.ts`

- 在边界包围盒内建规则采样网格，用三角化的精确掩膜（扣孔洞）筛出迹地像元，
  逐格取过火指数并按 4 个阈值分为 5 级（未过火 / 轻 / 中 / 重 / 极重）。
- 分级面积按格点计数估计后用多边形精确面积归一化，因此与面积模块完全一致。
- 分级栅格直接作为填充纹理（UV 按栅格范围归一化），切换阈值即时反映到三维视图。

### 交互

- **拖动顶点**：逐帧重建多边形 → 重新三角化 → 更新填充与分级，松手后一次入历史。
- **插入/删除**：Shift+点击边线插入，Alt+点击顶点删除；屏幕空间命中测试（像素容差），
  边界很密时也不会误咬相邻顶点。
- **点击查询**：点迹地内任意位置，浮层显示该处坡度、高程、过火指数、受损等级、距边界距离。
- **面积/周长**：顶栏与底栏实时刷新，来源为同一套派生数据。

### 持久化与导出

- 项目（含缩小后的影像 JPEG、量化后的 DEM、边界、参数）存入 `localStorage`，
  刷新自动恢复；体积超限时自动降分辨率重试。
- GeoJSON 输出 `Polygon`/`MultiPolygon`（含孔洞、环闭合），WGS84 时换算为 CRS84
  经纬度；属性含面积、周长、顶点数、提取参数、参考色与 5 级分级的面积/占比/均值。

## 已知限制

- 影像按最长边 1600 px 读取、指数场最长边 768 px 计算，超大正射影像会先降采样。
- 贴地填充细化预算约 11 万三角形；拖动时降为约 4000 三角形的预览网格，
  松手后恢复完整精度（画面右下角无提示，属预期行为）。
- 中文地名/项目名会进入 GeoJSON 属性；导出坐标精度为 7 位小数（经纬度约 1 cm）。
