# 🌞 太阳影子小街区

给幼儿园大班孩子做的太阳影子观察小实验:一个可以拖太阳、拖小人、玩路灯的三维小街区。
SolidJS + three.js 实现。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
npm run preview  # 预览构建结果
```

## 玩法

- **拖太阳**:高度角 10°~80°、方位角绕一圈,影子跟着变长变短、转方向
- **正午 / 傍晚预设**:右上角一键切换,对比影子长短(太阳越低越红、天越昏黄)
- **拖小人**:直接在场景里拖动三个小人,看影子交叠
- **路灯**:两盏路灯是点光源(立方体阴影贴图),可以单独关掉,看那一片影子消失
- **材质**:地面/墙面粗糙度可调;越粗糙,影子边缘越散(柔化核自动放大,模拟效果)

## 阴影技术参数(左侧面板)

| 功能 | 说明 |
|---|---|
| 级联阴影 CSM | 阳光按视距分 3 级(近/中/远),远处精度低,交界处淡出过渡 |
| 贴图分辨率 | 512~2048 可调 |
| 阴影偏移 / 法线偏移 | 滑块微调,治阴影痤疮 |
| 柔化采样核 | PCF 采样半径 0~16 |
| 调试视图 | 阴影贴图本体(左下角小窗,可选近/中/远级)、级联分层染色(红=近 绿=中 蓝=远)、深度视图 |

## 版本记录与对比

- 每次调整(滑块、预设、拖小人)都会自动存成一个版本(右侧面板)
- 勾选任意两个版本 → 下方出现对比:影长条形图 + 全部光源/阴影参数差异表
- 每个版本可以 ⏪ 一键恢复或 🗑 删除

## 小技巧

URL 参数可以直接定位到某个状态,方便课堂演示:
`?el=14&az=255`(高度角/方位角)、`?dbg=cascade`(调试视图:shadowmap / cascade / depth)
