# 轮毂造型实时替换与间隙检查工作台

参数化轮毂造型替换、整车装配可视化与轮拱间隙检测工具。

## 技术栈

- **TypeScript + SolidJS**：细粒度响应式状态，滑杆拖动只触发最小更新
- **three.js**：参数化几何生成、场景与 OrbitControls 交互
- **three-mesh-bvh**：轮拱内表面 BVH 加速射线检测，四轮全量重算在一帧内完成
- **Vite**：开发服务器与生产构建

## 启动

```bash
npm install
npm run dev      # 开发服务器（默认 http://127.0.0.1:5180）
npm run build    # 类型检查 + 生产构建
npm run smoke    # headless 冒烟测试（几何生成 / BVH / 间隙数值）
```

### 六款内置样式

经典直辐 `straight`、双五辐 `twin`、旋风扭转 `twist`、网状交错 `mesh`、
封闭盘面 `dish`、涡轮扇叶 `turbine`。点击款式卡片即替换当前选中轮位。

### 参数（右侧面板）

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 辐条数量 | 5–10（整数） | 控制各款式辐条/扇叶/开窗数量 |
| 盘面深度 | 0–60 mm | 辐条根部与中心法兰沿轴向的下沉量 |
| 轮辋直径 | 340–440 mm | 轮辋尺寸，轮胎外径 = 轮辋 + 双侧胎侧 |
| 偏距 | −40–120 mm | 车轮沿车轴方向外移，越过轮拱边界即标红警示环 |

切换轮位后参数面板自动同步该轮位当前数值；整车视角下四个车轮各自实时更新。

### 间隙检测原理

1. 四个轮拱的翼子板内衬（圆柱弧面）与外侧封盖环合并为单一网格，构建一次 BVH；
2. 每个轮位从轮胎外廓沿 25 个周向方向 × 3 个轴向倾斜角发射射线（共 75 条），
   `firstHitOnly` 取最近命中，换算为轮胎到轮拱内表面的最小间隙；
3. 状态分级：`< 5 mm` 干涉（红）、`< 25 mm` 偏紧（琥珀）、其余安全（绿）；
   偏距导致轮胎越过轮拱侧面边界时直接判干涉并点亮红色脉冲警示环；
4. 任意参数变化后由渲染帧调度四轮全量重算，结果显示在底部卡片，
   视口中以小球标出最小间隙命中点。

### 聚焦与截面

点击「聚焦」或顶部轮位后相机平滑过渡到该车轮，显示轮拱截线（青色）
与当前轮胎外廓截线（琥珀色），方便直接判读间隙；回到整车视角恢复全局观察。

## 目录结构

```

  constants.ts            几何常量、参数范围、轮位坐标
  types.ts                共享类型

```
