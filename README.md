# 菇房通风气流场可视化工具

把菇房离散成三维体素网格, 用体素风场 + 拖尾粒子展示通风气流, 并提供水平/垂直剖面视图、
风机设置面板与风场数据导出。

技术栈: **TypeScript + Svelte 5 + three.js + postprocessing**, Vite 构建。

---

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 产物在 dist/
npm run preview
```

要求 Node 20+、支持 WebGL2 与 Web Worker (`OffscreenCanvas` 不需要)。

---

## 功能

| 需求 | 实现 |
| --- | --- |
| 体素风场渲染器 | 房间离散为 **160 × 80 × 100 = 1,280,000** 体素 (0.08 m), 每个体素存速度矢量与标量风速 |
| 进风口 / 回风口 / 风机朝向 | 风机以 `(墙面, u, v)` 参数化, `tilt` (水平偏转) 与 `pitch` (仰角) 控制出流方向 |
| 粒子沿体素场推进 + 拖尾 | CPU 上三线性采样体素速度推进粒子; 每颗粒子记录 14 点拖尾带, 顶点着色器广告牌展开 |
| 菇架简化盒体 + 深度遮挡 | 每层搁板 / 立柱为盒体网格, 写深度; 粒子 `depthTest: true`, 被菇架与墙体正确遮挡 |
| 水平切片 + 垂直切片 | 水平切面 (按 Y) + 两个垂直切面 (纵切沿 X 固定 Z / 横切沿 Z 固定 X) |
| 剖面速度色带 + 方向箭头 | 切面贴图按 6 档色带着色; 面上的速度矢量投影后画成锥形箭头 |
| 风机面板改方向/风量后全场重算 | 任意参数变化 → Web Worker 重算风场 → 粒子、剖面、统计同步刷新 |
| 风场数据导出 | ZIP: 体素速度场 (JSON + 二进制) + 三个剖面 PNG + 6 档图例 + 说明 |
| 体素网格规模大数量级 | 1.28M 体素; 求解在 0.16 m 的粗网格上完成再上采样 |
| 粒子数量上限 | 上限 24,000, UI 可调, 默认 9,000 |
| 速度色带 6 档 | 固定 6 档 (深蓝 → 红), 断点按进度分位数自动选取 |
| 切片滑杆移动高度 | 每种切面都有滑杆; 水平切面按 Y, 纵切按 Z, 横切按 X |
| 拖动风机时剖面/粒子同步跟随 | 墙面平面上拖动圆盘, 松手后完整重算; 拖动中约每 0.5 s 用快速模式重算一次 |

## 物理模型

### 网格

| 网格 | 尺寸 | 用途 |
| --- | --- | --- |
| 求解网格 | 80 × 40 × 50 = 160k (0.16 m) | 构造速度 + 压力投影 |
| 风场网格 | 160 × 80 × 100 = 1.28M (0.08 m) | 粒子采样 / 切片 / 导出 / 统计 |

### 步骤

1. **体素化** — 房间边界为墙; 菇架按盒体填充 (搁板按粗网格厚度加厚, 保证每层至少阻断一格);
   风机在边界墙体上的圆盘区域记为"开口"。
2. **构造速度场** (单元中心)
   - 射流: 每个风口是一个高斯断面的射流, 断面随距离扩张, 轴向指数衰减;
     回风口是抽吸汇, 有效半径更大。
   - 环流: 用流函数 `ψ = A·sin(πx/Lx)·sin(πy/Ly)` 生成解析无散度的二维滚转,
     叠加 `(x,z)` 面内的第二个矢量势做侧向扩散, 并按菇架两侧走廊加权;
     这保证远离射流的区域也有合理的流动方向。
   - 层间通道: 搁板间隙内沿 X 加速。
3. **MAC 压力投影** — 速度映射到交错网格的面速度, 红黑 SOR 解压力泊松方程,
   使每个流体单元的离散散度为零 (`Σ面通量 / h = 0`)。风机开口是给定通量面 (`FACE_FIXED`)。
   - 进/回风总风量不平衡时自动按小的一侧平衡, 并在界面提示。
   - 迭代压力场会被缓存, 下一次求解热启动。
4. **上采样** — 粗网格速度三线性插值到细网格; 邻居为实体时归一化权重 (不产生零速薄壳),
   再做两次局部平滑让搁板边缘有连续流动。
5. **空气龄** — 从射流核心出发沿逆流做最短路松弛, 归一化到 0..1, 用于粒子着色的"空气龄"模式。

### 质量守恒验证

`solver-smoke.ts` 会打印投影后的散度 (`residualDivergence`, 典型 < 0.1 s⁻¹)。
`particle-leak.ts` 用数千个粒子推进 600 步, 确认没有粒子穿出房间。

## 渲染

- **粒子**: 每颗粒子由 14 个广告牌四边形组成一条拖尾带。拖尾点按**走过的距离**记录
  (每 5 cm 一点), 所以快慢不同的流线拖尾长度一致。粒子进入实体、超出房间或寿命到期即新生,
  新生时沿逆流回溯预填拖尾, 避免"凭空出现"。
- **遮挡**: 菇架是写深度的实体网格, 粒子材质 `depthWrite: false, depthTest: true`,
  因此菇架后方的拖尾段会被正确剔除。
- **切片**: 每种切面单独一张 `THREE.DataTexture`; 实体体素透明, 流体体素按 6 档色带上色。
  方向箭头是切面上每 0.5 m 一个锥体, 速度矢量投影到切面内, 长度随速度。
- **后处理**: `EffectComposer` + `Bloom` + `ACES ToneMapping` + `SMAA` + `Vignette`。

### 交互

- 左键拖空白旋转, 滚轮缩放, 右键平移。
- 鼠标悬停风机圆盘时光标变 `grab`, 按住即可在这面墙上拖动; 拖动过程中粒子与剖面实时跟随,
  松手后做一次完整解算 (含空气龄)。
- 风机面板可改风量、风口半径、水平偏转、仰角、安装墙面与位置。

## 导出

「导出数据」生成 ZIP:

```
voxel-field.json   网格尺寸、坐标约定、颜色断点、风机参数、统计、二进制布局说明
fluid.u8           流体掩码 1 = 空气 (x + nx*(z + nz*y))
speed.i16          风速 mm/s
vx.i16 / vy.i16 / vz.i16   速度分量 mm/s
age.i16            空气龄相对值 0..10000
slice-horizontal.png / slice-vertical-x.png / slice-vertical-z.png
slice-*.json       每张切面的模式、位置、尺寸
legend.png         6 档色带图例
README.txt
```

可选 1× / 2× / 4× 降采样; PNG 由内置编码器直接写出, 不依赖第三方图像库。

## 性能

在开发机上 (软件渲染 SwiftShader 仅用于自动化截图):

| 操作 | 耗时 |
| --- | --- |
| 完整解算 (220 次 SOR + 空气龄) | ~2.8 s |
| 拖动模式 (30 次 SOR, 跳过空气龄与平滑) | ~0.55 s |
| 粒子更新 (9,000 颗 × 14 点拖尾) | ~8 ms/帧 |

求解在 Worker 中执行, 主线程渲染不中断。真实 GPU 上粒子渲染的主要瓶颈是透明叠加填充率,
可用「粒子数」「粒子亮度」调节。
