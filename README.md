# 低空航路气象体积渲染工具

TypeScript + Vue 3 + three.js + postprocessing 实现的低空无人机航路气象分析工具。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm run typecheck  # 类型检查
npm run smoke      # 数据管线冒烟测试(无需浏览器)
```

## 功能模块

### 1. 航路编辑
- 起终点 + 最多 4 个途经点的水平位置编辑(km 坐标,60×60 km 空域)
- 飞行高度带(带底/带顶,米)编辑,实时校验越障余度(地形 +150 m MSA)
- 预设航路、航段长度/航向一览

### 2. 体积视图
- 三维纹理(128×48×128)光线步进(raymarching)渲染雷暴单体与层云,梯度光照
- 24 帧时间序列:时间滑块/播放,3 个雷暴单体随风场移动
- 3 档密度阈值(低·通透 / 中 / 高·浓稠)改变云体通透度
- 后处理链:深度重建的体积雾 + 双色调色彩映射 + 泛光 + 暗角,均可开关
- 地形底图、航路高亮(高度带幕帘 + 航路点标杆)开关
- HUD 显示沿航路云底高度统计

### 3. 剖面分析
- 沿航路垂直剖面(220 采样点 × 60 高度层),能见度色带叠加
- 最低安全高度线(MSA,地形 +150 m,±2 km 窗口取最大)、云底线、高度带叠加
- 按航段统计最低/平均能见度与越障余度
- 导出 JSON(含每个剖面采样点的完整能见度廓线)与 CSV(采样点表 + 航段汇总)

## 体数据与缓存

- 体数据由 `src/data/weatherSim.ts` 程序化模拟:3 个雷暴单体(高斯水平衰减 × 垂直廓线 × fbm 扰动)+ 层云背景,24 帧时序
- 每帧切分为 4×3×4 共 48 个分块(32×16×32),生成后写入 IndexedDB(`src/data/volumeCache.ts`),再次加载同一帧时直接拼装,内存 LRU 保留最近 6 帧
- 能见度由密度经 Koschmieder 公式 V = 3.912 / β 换算

## 目录结构

```
src/
  data/        噪声、体数据模拟、分块缓存(IndexedDB)、帧存取
  three/       体积光线步进材质、场景管理、自定义后处理效果
  analysis/    剖面采样、能见度、MSA、云底统计
  export/      JSON / CSV 导出
  components/  航路编辑 / 体积视图 / 剖面分析 三个模块
```
