# 车身分色贴膜预览工具

基于 **TypeScript + React + Babylon.js（WebGPU 优先，WebGL2 自动回退）** 的车身贴膜分色设计工具。
加载车身后可在曲面上用笔刷绘制分色边界，边界把车身划分成若干色块，逐块填充哑光 / 亮面 / 金属三类共 12 种膜色，并自动生成贴合曲面的接缝线。

## 功能

| 区域 | 能力 |
| --- | --- |
| 左侧膜色库 | 哑光 / 亮面 / 金属三类，每类 4 色共 **12 种膜色**，选中后进入填色模式 |
| 中间视口 | ArcRotateCamera 左键旋转、滚轮缩放；笔刷沿曲面采样绘制，笔刷半径可调 |
| 右侧接缝面板 | 分色边界自动生成接缝管，接缝宽度可调；跨越车门缝 / 翼子板缝保持连续 |
| 底部膜材参数 | 粗糙度 / 金属度滑杆，调整后整车身 PBR 材质同步更新 |
| 顶部方案栏 | 最多保存 **6 套**方案（带缩略图）、导出 / 导入 JSON 配色方案 |
| 模型加载 | 支持 `.glb / .gltf / .obj / .stl`，自动归一化尺寸并重建 UV |

## 核心实现

- **曲面笔刷**：射线拾取命中三角面，记录世界坐标、几何法线、UV 与面片世界/UV 尺度；
  相邻采样点按世界距离去重，笔画在车身贴膜纹理（2048² `DynamicTexture`）上栅格化。
- **分区算法**：以笔画蒙版为屏障，对三角面邻接表做 BFS 连通分量划分。
  邻接边用规范化字符串键建立，避免大顶点索引下数值哈希碰撞导致拓扑断裂。
- **接缝管**：对每条笔画的曲面采样点沿法线微抬升后用 `MeshBuilder.CreateTube` 生成固定世界半径管体，
  跨板件缝连续对齐、缩放不变形。
- **UV 展开**：演示车身与无 UV 模型采用绕车长轴的柱面展开，环绕接缝置于车底，绘制主面无镜像断裂。
- **方案文件**：导出 JSON 含每条笔画采样点（位置/法线/UV）、每个色块的膜色编号、笔刷与接缝参数、膜材参数；导入后完整还原。

## 开发

```bash
npm install
npm run dev        # 启动开发服务器（默认 5199 端口）
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

> WebGPU 不可用的环境（如无适配器的无头浏览器）会自动回退到 WebGL2，界面右上角显示当前引擎。

## 自动化测试

`scripts/cdp-test.mjs` 通过 Chrome DevTools Protocol 驱动无头浏览器，覆盖填色、曲面绘制、
闭合环分区切割、接缝生成、膜材参数联动、方案保存缩略图、导出文件结构、清空还原、撤销与 6 套上限，
共 27 项断言（需先 `npm run dev`）：

```bash
# 需要一个带远程调试端口的 Chrome；脚本会自行拉起无头实例
node scripts/cdp-test.mjs
```

## 目录结构

```
src/
  App.tsx              应用装配与 React 状态
  CarWrapEngine.ts     Babylon 引擎封装：拾取/绘制/分区/接缝/导入导出
  demoCar.ts           程序化演示车身（含车门缝、翼子板缝、轮拱、车轮）
  filmLibrary.ts       12 种膜色定义
  storage.ts           方案本地持久化（6 套上限）
  types.ts             领域类型与方案文件结构
  components/          膜色库、接缝面板、材质面板、方案栏、视口工具条
```
