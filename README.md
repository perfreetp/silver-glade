# 机房线缆走线预览工具

基于 **three.js** 的机房线缆走线规划与预览工具。在机柜布局中点选两个端口，自动在机柜包围盒之间搜索避障路径，将路径平滑为带弯曲半径约束的线缆曲线，支持控制点拖动调整、碰撞穿模标红、多候选路径对比与工程文件导出。

## 运行

```bash
node server.mjs
# 打开 http://localhost:8080  （端口占用时可用 PORT=8123 node server.mjs）
```

> 必须通过 HTTP 访问（Web Worker 使用 ES Module，`file://` 协议下无法加载）。three.js 从 jsDelivr CDN 加载，首次运行需要联网。

## 四个功能模块

| 模块 | 面板 | 能力 |
|---|---|---|
| ① 机柜布局与端口选择 | 左上 | 20 个机柜 / 640 个端口的实例化机房；点击端口选 A/B 两点；包围盒与地面网格显隐；一键批量生成 300 条线缆做规模验证 |
| ② 避障路径搜索 | 左下 | 路径搜索在 **Web Worker** 中运行（不阻塞渲染）；6 邻接三维 A* + 二叉堆；同对端口产出 3 条结构差异化候选；弯曲模式与弯曲半径调节 |
| ③ 线缆曲线渲染视口 | 中部 | 全部线缆合批到**单个 InstancedMesh**（300 条 × 120 段 = 3.6 万实例，1 次绘制调用）；碰撞段逐实例标红；全局粗细/颜色；OrbitControls 漫游 |
| ④ 路径调整与导出 | 右侧 | TransformControls 拖动控制点（网格吸附、双击插点、右键删点）；单条颜色/粗细；长度清单表格；导出路径点集 JSON 与长度清单 CSV |

## 核心技术点

### 避障搜索（`src/workers/pathWorker.js`）
- 三维正交网格（单元 0.4 m，约 50×13×45 = 2.9 万单元），机柜 AABB 按 0.15 m 膨胀后栅格化占用，保证线缆不贴墙穿模
- 6 邻接 A*，曼哈顿启发式（可采纳），二叉堆开表
- 三条候选通过**不同高度的必经航点 + 分段 A*** 产生结构性差异：
  - 候选 1 均衡走线（无航点，纯最短）
  - 候选 2 顶部桥架（强制经过 y=4.6 m 走廊）
  - 候选 3 低位走线（强制经过 y=0.6 m 走廊）
- 起终点/航点单元强制开放，分段拼接；单段不可达时整条候选标记失败而不影响其他候选

### 线缆曲线（`src/cableCurve.js`）
- **圆角折线模式**：解析折线每个转角，按切线长 `d = r·tan(θ/2)` 求切点，用 3D 圆弧（圆心 = 角点沿内角平分线偏移 `r/cos(θ/2)`）精确实现弯曲半径；短边自动收缩半径防止自交；按弧长等距重采样
- **样条模式**：以圆角切点/弧中点为控制多边形，向心 Catmull-Rom 平滑后按弧长取点
- 外接圆半径法估算成品曲线的最小弯曲半径

### 碰撞检测（`src/collision.js`）
- 逐采样段对全部机柜 AABB 做 slab 线段-盒体求交，盒体按线缆半径膨胀（保守判定）
- 返回穿模段索引集合（驱动逐实例标红）、穿透长度、命中机柜清单

### 局部更新与合批渲染（`src/cableStore.js` / `src/cableLayer.js`）
- 控制点拖动后**只重算该条线缆**的曲线与碰撞（实测 < 0.3 ms），仅覆写其占用的实例区间，不触碰其他 299 条
- 圆柱段 + 实例缩放表达不同线径，实例颜色随线缆颜色/选中态/碰撞态变化

## 导出格式

- **JSON**（`cable_paths_<时间戳>.json`）：每条线缆含端口、方案、控制点、121 个采样点、长度、最小弯曲半径、碰撞段索引与命中机柜
- **CSV**（`cable_lengths_<时间戳>.csv`，带 UTF-8 BOM，Excel 直接识别中文）：11 列长度清单

## 目录结构

```
src/
  config.js          全局参数（机房/网格/机柜/端口/线缆/候选方案）
  grid.js            三维网格、占用栅格、坐标互转、共线化简
  workers/pathWorker.js   Worker 内 A*（分段搜索、二叉堆）
  workerClient.js    Worker Promise 封装
  room.js            机柜/端口实例化布局、AABB、端口状态着色
  cableCurve.js      圆角折线/样条/弧长重采样/最小半径
  collision.js       线段-AABB slab 碰撞
  cableStore.js      线缆数据层、候选切换、局部重算、统计
  cableLayer.js      InstancedMesh 合批渲染
  waypointEditor.js  控制点 TransformControls 拖动/增删/吸附
  exporter.js        JSON/CSV 导出
  main.js            场景装配、拾取交互、面板联动
.verify/             Node 逻辑测试与 CDP 浏览器冒烟测试（不随运行时加载）
```

## 测试

```bash
npm test                 # 4 套 Node 逻辑测试（A*/曲线碰撞/候选差异/集成）
node .verify/smoke-cdp.mjs       # 真实 Chrome 加载 + 300 条规模冒烟（需要本机 Chrome）
node .verify/smoke-interact.mjs  # 候选切换/滑块/导出文件内容校验
```

验证基线：300 条线缆 Worker 搜索均摊约 2~3 ms/对（含 3 候选），自动路径零碰撞，单条拖动重算 < 0.3 ms。
