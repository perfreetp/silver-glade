# 古建屋面残损分布可视化工具

基于 **TypeScript + Vue 3 + Babylon.js（WebGPU 优先，WebGL2 回退）** 的勘察残损三维可视化工具，
把瓦面残损区域叠加到屋面三维网格上，按残损程度分四档着色显示。

## 运行

```bash
pnpm install
pnpm dev        # 开发服务器 http://127.0.0.1:5173
pnpm build      # 类型检查 + 生产构建
pnpm test:e2e   # headless 端到端测试（需本机 Edge/Chrome，自动定位 Edge）
```

## 四个模块与使用流程

### 1. 屋面网格加载
- 默认加载**程序化举折屋面**（带瓦垄余弦起伏、檐口起翘的高度场，开箱即用）。
- 支持导入 **GLB / glTF / OBJ / STL** 模型，多网格自动合并、归一化到 20m 尺度。
- 按坡度与垄向生成两套参考线：垄向线（暖黄，沿坡向对齐瓦垄周期）、坡度线（冷蓝，等 u 横线）。
- 面板实时显示三角面数、顶点数、平均/最大坡度、网格包围盒 min/max/尺寸。
- 导入模型通过 XZ 均匀网格加速的竖直投影器（面积加权平滑法线）支撑高频贴合。

### 2. 残损面片贴合
- 进入绘制模式后在屋面上**按住左键勾勒轮廓**，松开即生成面片。
- 轮廓边按 0.35m 步长细分、逐点投影到屋面；内部三角形做**递归中点细分**贴合曲率，
  相邻三角形共享边中点，无裂缝。
- 面片沿平滑法线**整体抬升**（滑块 0–0.3m 可调），消除与瓦面共面闪烁；
  面片间另加 1.5mm 级差防止互相穿插共面。
- earcut 平面三角化，支持任意简单多边形。

### 3. 分层渲染
- 所有残损面片**合并为单个 Mesh**，顶点色分四档着色（轻微→严重：绿/黄/橙/红），
  千面片仍为 1 个 submesh、填充层 1 次绘制调用。
- 半透明叠加（不透明度可调），`needDepthPrePass` 深度预通道先写深度再混合，
  解决密集面片互相穿插时的半透明排序错误。
- 双面渲染 + 对屋面深度测试，保证任意视角抬升面片不被瓦面错误遮挡。
- 提供线框模式、参考线开关。

### 4. 等级调整与导出
- 三档界阈值（t1/t2）**拖动即时重算**，只重写颜色缓冲（O(n)，不重建几何）。
- 每个面片可手动覆盖等级（自动分档规则：s<t1→1级，s<t2→2级，s<0.85→3级，否则4级）。
- 导出**残损图层 JSON**（含全部轮廓/等级/渲染参数，可回导恢复）。
- 导出**等级分布清单 CSV**（UTF-8 BOM，含分档汇总与逐面片明细，Excel 可直接打开）。

## 实时读数（HUD）

残损面片数、图层三角面数、绘制（重建）耗时、投影贴合耗时、滚动平均帧耗时/FPS、绘制调用。
面板内 `+200 / +1000 面片` 按钮用于性能压力测试（实测千面片重建约 110ms）。

## 目录结构

```
src/
  types.ts                 类型、等级元数据、severity→grade 分档规则
  store.ts                 Vue 响应式全局状态
  exporter.ts              JSON 图层 / CSV 清单导出
  engine/
    BabylonService.ts      引擎/场景/交互/IO 总编排
    ProceduralRoof.ts      程序化举折屋面高度场（解析投影/法线/统计）
    MeshProjector.ts       导入模型的均匀网格加速竖直投影器
    ReferenceLines.ts      垄向/坡度参考线
    DamageLayer.ts         合并 Mesh、earcut、曲率细分、抬升、颜色重算
  components/              四个模块面板 + 性能 HUD
tests/e2e.mjs              Puppeteer 端到端测试（19 项断言）
```

## 关键设计取舍

| 问题 | 方案 |
|---|---|
| 千面片性能 | 单 Mesh 合并 + 顶点色，几何重建一次性提交，等级调整只更新颜色缓冲 |
| 半透明穿插排序错误 | 深度预通道（opaque 写深度 → transparent 混合），不依赖逐对象排序 |
| 共面闪烁 | 法线抬升（用户可调）+ 面片间微小级差 |
| 任意视角遮挡 | 双面渲染 + 抬升面片对屋面做常规深度测试 |
| 导入模型贴合 | XZ 均匀网格粗筛 + 竖直线三角形求交 + 重心插值平滑法线 |
